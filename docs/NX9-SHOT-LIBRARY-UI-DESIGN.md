# NX9 公共镜头库 · UI 设计规格

> **状态**：D0 壳 + 117 条中立种子已灌入 `BUILTIN_BACKLOT_TEMPLATES`（`shot-library-seeds.ts`）  
> **日期**：2026-08-11  
> **范围**：仅「公共」scope 的 `kind:'shot'` 运镜词典浏览 / 筛选 / 轻编辑壳层  
> **不在范围**：风格库、私有项目建镜头、镜表强绑 `shotAssetId`（Shot-01，可后置）

---

## 0. 一句话目标

把公共镜头库做成**可扫视的运镜词典**：一眼读出「怎么动、干什么用」，一键 `@镜头` 写入下游；视觉上融入 NX9 暖色壳层，**不做成独立「运镜广场」产品页**。

---

## 1. 参考取舍（学什么 / 弃什么 / 超什么）

两张参考图共同点：分类 pill + 大图网格 + 短说明。这是对的，保留。

| 维度 | 参考 A（浅色运镜库） | 参考 B（深色运镜广场） | NX9 决策 |
|------|----------------------|------------------------|----------|
| 容器 | 独立页面标题「运镜库」 | 独立 Modal「广场 / 收藏 / 我的」 | **嵌在素材库 · 公共 · 镜头 Tab**；不另开产品岛 |
| 主题 | 浅色、圆角、呼吸感 | 深色赛博、统一角色海报 | **沿用 `bg / surface / line / brand / ink`**；禁止深色广场、禁止紫光 |
| 封面 | 静帧插画，角色统一 | 静帧海报，角色统一 | **动效优先**：有 `gifUrl` 用动图；无动图用静帧 + 「静帧」角标 |
| 信息 | 名 + 一句用途 | 几乎只有名 | **名 + 用途一行 + 景别/运镜芯片**（多一层可读性） |
| 分类 | 基础控制 / 跟拍 / 转场… | 无横向族分类 | **运镜族**为主筛；景别为次筛（见 §3） |
| 收藏 | 无 | 独立 Tab「我的收藏」 | **工具条「仅收藏」开关**（Shot-03），不拆第三套导航 |
| 「我的运镜」 | 无 | 有 | **不做**：镜头仅公共词典，用户自建也落在公共库条目，不另开「我的」 |
| 生产动作 | 无 | 星标 | **⋯：编辑 / 收藏 / 复制@ / 锁定 / 删除**；卡片不点空白进编辑 |

**超越点（相对两张参考）**

1. **运动可读**：运镜库的主视觉是「动」，不是好看的静帧海报墙。  
2. **词典元数据上卡面**：景别码、运镜词、推荐时长可见，扫一眼可写分镜。  
3. **与素材库同壳**：公共/私有、健康条、回收站、锁定 Prompt 同一套心智，不学「广场」另起炉灶。  
4. **用途文案位**：`purpose` 固定为一行「导演意图」，比纯标题更可点选决策。  
5. **选取态**：从分镜/帧编辑器 `openAt({ tab:'shot' })` 进入时，主操作变为「写入本镜」，浏览壳不变。

## 2. 产品定位（写进交互的边界）

```text
风格库 = 画面美学（色调、材质、时代感）
镜头库 = 机位与运镜（怎么拍、怎么动、服务什么戏剧目的）
```

- Scope：**仅公共**（已落地：私有顶栏不展示镜头）。  
- SSOT：公共库 `BacklotWorkspaceItem` + `ShotCreativeExtension`。  
- 下游：`@镜头:名`、分镜 Prompt enrich、（后续）镜表绑定 / 导演台同 id。  
- 不做：角色设定板级媒体墙；不做情绪库替代品（氛围用 `emotionTags` 芯片即可）。

## 3. 信息架构

```text
素材库 Modal
└─ 公共
   └─ Tab「镜头」（语言词典组）
      ├─ 浏览态 ShotPlazaBrowse（主区全幅）
      │    工具条：搜索 · 计数 · 体系 → 分类 → 运镜族 · 景别次筛 · 仅收藏 · 新建
      │    主区：ShotCardGrid
      │    「⋯」→ 编辑 / 收藏 / 复制@ / 锁定 / 删除
      └─ 编辑态 ShotLexiconEdit（全页替换主区，轻量左右栏）
           顶栏：← 返回 · 名称 · 复制@ · 收藏 · 锁定
           左：档案（用途 / 体系 / 分类 / 运镜族 / 景别 / 时长 / 情绪标签 / Prompt）
           右：动图预览 · 静帧备选 · 上传
```

### 3.1 三级层级（主导航）

```text
体系（L1）→ 分类（L2）→ 运镜族（L3）→ 景别（次筛）
```

| 层 | 字段 | 示例 |
|----|------|------|
| L1 体系 | `lexiconSystemId` | 体系一 · 实拍 / 体系二 · AI/CG |
| L2 分类 | `lexiconCategory` | 基础推拉变焦、环绕、国漫打斗… |
| L3 运镜族 | `moveFamily` | 固定 / 推拉 / 摇移 / 跟拍 / 升降 / 环绕 / 特殊 |
| 次筛 | `shotSize` | 特写 · 近景 · 中景 · 全景… |

### 3.2 运镜族（摄影动作粗分）

参考图的「基础控制 / 人物跟拍…」偏营销口吻。NX9 用**摄影语言族**，便于你后续批量灌提示词时挂类：

| `moveFamily` | 中文 | 典型条目 |
|--------------|------|----------|
| `static` | 固定 | 固定镜头、锁定构图 |
| `dolly` | 推拉 | 前推、后拉、滑轨推近 |
| `pan_tilt` | 摇移 | 左摇、右摇、上摇、下摇 |
| `track` | 跟拍 | 跟随、侧面跟、迎面跟 |
| `crane` | 升降 | 升起、落下、摇臂 |
| `orbit` | 环绕 | 盘旋抬升、环绕下降 |
| `special` | 特殊 | 手持、POV、荷兰角、甩镜 |

- 顶栏 pill：**全部** + 上表各族。  
- 未标注族的旧条目：归入「全部」，编辑时可补。  
- **不要**把「情绪强化」「揭示转场」做成一级族——那是 `purpose` / `emotionTags` 的事，避免和运镜物理动作混层。

### 3.2 景别次筛（可选折叠）

工具条右侧或第二行：`全部景别 | ECU | CU | MS | WS | …`（复用现有 `CAC_SHOT_SIZES`）。  
默认收起为「景别 ▾」，避免和运镜族抢视线（参考 A 只有一层 pill，我们多层但默认安静）。

## 4. 视觉语言（匹配项目，不抄参考）

### 4.1 Token

| 用途 | Token |
|------|--------|
| 页面底 | `bg`（暖纸色） |
| 卡片面 | `surface` + `border-line` |
| 强调 / 选中 pill | `brand` 浅底 + `brand` 字（青铜，非黑底白字大胶囊） |
| 正文 | `ink`；次要 `ink/55`；提示 `ink/40` |
| 圆角 | `rounded-xl` 卡片；pill `rounded-full`；与角色库一致 |

**禁止**：深色全幅广场、统一赛博角色海报墙、紫色光晕、过厚阴影、把「全部」做成高对比黑胶囊主导视觉。

### 4.2 与角色/实体卡的差异（刻意）

| | 角色 / 服道场 | 镜头词典卡 |
|--|----------------|------------|
| 比例 | 竖图 3:4 或景 4:3 | **横图 16:10**（电影画幅感） |
| 主媒体 | 人/衣/空间静帧 | **GIF 优先**，悬停播放（若浏览器策略需 click-to-play 则显示播放钮） |
| 底栏 | 名 + ⋯ | 名 + 用途一行 + 元数据芯片 + ⋯ |
| 角标 | 缺图 / 未锁 / 已锁 | **动图 / 静帧** · 收藏星 · 未锁 / 已锁 · 缺 Prompt |

横画幅 + 运动预览 = 扫视时立刻知道「这是运镜词典，不是角色库」。

## 5. 卡片解剖 `ShotCard`

```text
┌─────────────────────────────┐
│  [动图|静帧]     ★     ⋯    │  ← 左角媒体态；右收藏（可点）；⋯ 菜单
│                             │
│         16:10 预览区         │
│      （无图：虚线「无预览」）  │
├─────────────────────────────┤
│  镜头前推                    │  ← label，单行 truncate
│  强调表情与反应              │  ← purpose，单行，ink/50
│  MS · 推 · 3s                │  ← shotSize · cameraMove · durationSec
└─────────────────────────────┘
```

### 5.1 交互细则

| 行为 | 规则 |
|------|------|
| 点卡片空白 | **不进编辑**（与角色库一致） |
| 点 ⋯ → 编辑 | 进入 `ShotLexiconEdit` |
| 点 ★ | 切换 `creative.favorite`，不打开菜单 |
| 悬停预览 | 有 gif 则播放；底栏短暂露出「复制 @镜头:名」幽灵按钮（可选 P1） |
| 选取态（从分镜打开） | 卡片主点击 =「写入本镜」；⋯ 仍可编辑 |

### 5.2 空态 / 稀缺态

- 无条目：居中短句「公共镜头词典为空 · 新建或等待批量导入」。  
- 有条目无预览：灰色电影画幅占位 + 运镜族首字或简易矢量机位示意（**不要**假人物海报）。  
- 筛选无结果：保留 pill，提示「无匹配 · 清除筛选」。

## 6. 浏览工具条

单行优先，窄屏折行：

```text
[ 搜索运镜名称或用途…     ]  24 条
[全部][固定][推拉][摇移][跟拍][升降][环绕][特殊]   [景别 ▾]  [☆ 仅收藏]  [+ 新建]
```

- 搜索：命中 `label`、`purpose`、`cameraMove`、`promptEn`。  
- 计数：当前过滤后数量。  
- 「仅收藏」：落实 Shot-03。  
- 健康条：若公共镜头 Tab 挂健康过滤，指标用「缺 Prompt / 未锁定 / 无预览」；**不要**抄角色的「未使用」除非已有引用图。

## 7. 编辑态 `ShotLexiconEdit`（轻量，不抄角色圣经）

镜头是词典，不是人物资产。左右分栏继承壳层哲学，**栏内极简**：

**左栏**

1. 名称  
2. 用途 `purpose`（一行，placeholder：如「强调表情与反应」）  
3. 运镜族 `moveFamily`（pill 单选）  
4. 景别 `shotSize` + 运镜方式 `cameraMove` + 时长  
5. 情绪标签 `emotionTags`（内置芯片，已有）  
6. 运镜 Prompt（`promptEn` / structured shot prompt）+ 锁定  

**右栏**

1. 大预览：GIF 优先；可切换静帧 `exampleImageUrl`  
2. 上传动图 / 上传示例帧  
3. 一句话提示：「预览只说明运动，不绑定具体角色造型」

顶栏：返回 · 名 · `@` · 收藏 · 锁定。无「完整设定板」按钮。

## 10. 动效（克制、有存在感）

1. 运镜族 pill 切换：网格内容 crossfade 或短位移动画（≤180ms），不要整页闪白。  
2. 卡片悬停：`border-brand/35`（已有实体卡模式）+ GIF 起播。  
3. 收藏 ★：填充色过渡，无撒花。  

禁止：卡片悬浮上浮阴影层叠、光效扫光。

---

## 11. 选取态（下游打开时）

当 `openAt({ tab: 'shot', scope: 'public' })` 且带 `pickMode`（实现时可挂在 navigateRequest）：

- 工具条右侧出现提示条：「点选卡片写入当前镜头」。  
- 主点击 = 回调写入（`cameraMove` / `@镜头` / `shotSize` 按调用方约定）。  
- 不强制用户先「编辑」。

此为相对参考图的**工作流超越**：词典不仅好看，还能在创作路径里被点选消费。

---

## 12. 验收口诀

1. **一眼是运镜**：横画幅 + 动图/静帧角标，不会误认成角色卡。  
2. **两眼能决策**：看到用途行 + `MS · 推 · 3s` 就知道能不能用。  
3. **三步能引用**：⋯ 复制@，或选取态一点写入。  
4. **不像广场**：仍在素材库公共 Tab；暖色；无「我的运镜」分岛。  
5. **可灌库**：运镜族 + 用途 + Prompt 字段齐，便于你稍后批量导入提示词。

---

**设计结论**：学参考的「分类 + 大图网格 + 短用途」，弃深色广场与「我的」分岛；用横画幅运动预览、卡面元数据芯片、素材库同壳与选取态，形成 NX9 自己的公共运镜词典，而不是第二套运镜广场。
