## 0. 一句话结论

分镜台**主链骨架已通**（拆镜 → 镜表 → 线稿构图 → 确认交接），且职责收口 PRD 的大半入口约束已落地（镜表无「试出」、底栏无四按钮、模型在 Tab 外、嵌入预览藏 3D）。  
但要到**可生产级**，仍缺：**可后悔（删镜/撤销）、可停止（批量线稿）、确认状态不撒谎、成稿变更强提醒、按集隔离产物、交接真正打通导演台、巨型 hook 可维护与测例**。

## 1. 现状能力地图（已有，禁止重复造）

| 能力 | 锚点 | 说明 |
|---|---|---|
| 四步流程 Tab | `studioTab`: `breakdown` / `grid` / `compose` / `handoff` | 步骤条可点切换；**无完成态着色** |
| 从成稿拆镜 | `breakdownFromPackage` | 要求上游 `ScreenplayPackage.status==='confirmed'` |
| 多集拆镜队列 | `runQueueForEpisodes` + `EpisodeQueueBar` | 可暂停 / 继续 / 跳过 / 取消 |
| 增量补拆 | 粘贴文本 → 合并入镜表 | **写入前无解析预览** |
| 导入旧镜表 | `importLegacyBreakdown` | 用 `window.confirm` |
| 成稿变更检测 | `packageStale` + `packageSourceHash` | 仅文案提示，**无强 banner / 一键重拆 CTA** |
| 镜表宫格 | `ShotStoryCell` | 上传 / **线稿** / **编辑**（无试出 ✔） |
| 增镜 / 拆镜 / 合镜 | `addShotToBreakdown` / `split` / `merge` | **无删镜 API/UI** |
| 镜头导航筛选 | `all` / `uncomposed` / `unbound` | 无数量角标；点导航**不滚到卡片** |
| 构图工具条 | 批量线稿 / 宫格线稿 / 故事板大图 + `ComposerModelSelect` | 模型在 Tab 外 ✔ |
| 构图子 Tab | 「线稿预览」/「本集故事板大图」 | 预览嵌入 `StoryboardPreviewWorkspace`（embedded 藏 3D ✔） |
| 单镜编辑弹窗 | 第二层 `ScreenModal` | 字段全；保存会 `gridConfirmed:false`，**未必摘掉本集确认** |
| 交接 checklist | 镜数 / 覆盖率软阈 / 绑定 / 故事板 / 确认态 | 「打开导演台」**只 focus，不 spawn** |
| 底栏 | 本集摘要 +「确认本集」 | 无批量四按钮 ✔ |
| 就绪条 | 软/硬预检 + 构图强约束开关 | 文案偏工程化 |
| 导出 | `exportPack` | 偏开发向 JSON，非审片交付包 |

代码体量（工程债）：`use-storyboard-desk.tsx` **≈2780 行**（远超历史「Desk &lt;800」目标）。

## 3. 缺口总表

优先级：`P0` 会丢工作成果 / 状态撒谎 / 任务卡死 / 错交付；`P1` 效率与专业感；`P2` 打磨。

### 3.1 流程与信息架构（F）

| ID | 缺口 | P | 说明 |
|---|---|---|---|
| F-01 | 步骤条无完成态 | P1 | 有镜表/有线稿/已确认时不显示 `is-done` |
| F-02 | 冷启动引导偏「工程页」 | P1 | 拆镜页信息量大，缺「三步你会得到什么」 |
| F-03 | 就绪条文案工程化（emoji+硬/软） | P2 | 生产向应人话 + 明确阻断原因 |
| F-04 | 镜表 / 构图双入口出线稿 | P1 | 工具条批量 vs 嵌入预览「全出线稿」，用户不知以谁为准 |
| F-05 | 嵌入预览残留关键帧语汇 | P1 | 「评分」「重生低分」「提交批审」在线稿职责下应隐藏或降级 |
| F-06 | 顶栏集切换后，故事板大图可能串集 | **P0** | `contactSheetUrl` 挂在整节点 `storyboardPreview`，**未按 episodeId 分桶** |
| F-07 | 选中导航不联动滚到镜卡片 | P2 | 长集难定位 |
| F-08 | 筛选无计数 | P2 | 「未构图 (12)」更可决策 |

### 3.2 拆镜（B）

| ID | 缺口 | P | 说明 |
|---|---|---|---|
| B-01 | 成稿 stale 仅弱文案 | **P0** | 卡片 logline / hero 附带「成稿已更新」，无顶栏阻断条 +「重拆本集/全部」 |
| B-02 | 破坏性确认用 `window.confirm` | P1 | 与项目 `ConfirmHost` 层级/主题不一致（编剧台已踩过坑） |
| B-03 | 增量补拆无预览 | P1 | 粘贴后直接合并，无法先看将新增几镜 |
| B-04 | 重拆策略粗糙 | P1 | 全量覆盖 vs 仅未确认集 / 仅当前集，缺少产品选项 |
| B-05 | 拆镜失败集无「只重试失败」一键 | P1 | 队列有失败计数，缺聚合重试入口 |
| B-06 | 拆镜中可切 Tab / 关台 | P1 | 无运行互锁（对标编剧台 C-08） |

### 3.3 镜表运维（G）

| ID | 缺口 | P | 说明 |
|---|---|---|---|
| G-01 | **无删镜** | **P0** | runner 仅 add/split/merge，无 `removeShotFromBreakdown` |
| G-02 | 无拖拽重排镜序 | P1 | 合/拆改变结构，但不能自由调序 |
| G-03 | 无复制镜 / 批量选中 | P1 | 长集返工效率低 |
| G-04 | 线稿与编辑同用 Pencil 图标 | P2 | 辨识差 |
| G-05 | 删图/换图无确认 | P2 | 点击媒体即上传覆盖 |
| G-06 | 合镜规则不直观 | P1 | 「与前镜合并」失败只 appendLog，无 inline 提示 |
| G-07 | 无本地撤销栈 | **P0** | 误合镜/误重拆不可一键回退 |

### 3.4 构图 / 线稿（C）

| ID | 缺口 | P | 说明 |
|---|---|---|---|
| C-01 | **批量线稿不可停止** | **P0** | `for` 循环无 `AbortSignal`；拆镜队列反而可停 |
| C-02 | 宫格线稿同样不可停 | **P0** | 同上 |
| C-03 | 部分失败不可「只重试失败/缺图」 | P1 | 工具条总是打可见全集；预览侧有「补线稿」但双入口 |
| C-04 | 单镜线稿生成中无全局互锁提示 | P1 | `batchRunning` 挡单镜，但反向单镜进行时批量禁用体验一般 |
| C-05 | 线稿/批量成功不使本集确认失效（完整） | **P0** | 见 Q-01：确认态可能仍显示「已确认」 |
| C-06 | 故事板大图签名按可见镜，但 URL 全局一份 | **P0** | 与 F-06 同源 |
| C-07 | 「仅缺图」范围选择缺失 | P1 | scope 仅 visible/all 内部参数，UI 未暴露「缺图优先」 |
| C-08 | 无模型/连接失败的内联空态（工具条） | P1 | 多依赖 activity log |

| ID | 缺口 | P | 说明 |
|---|---|---|---|

| H-02 | 确认后编辑只清 `gridConfirmed` | **P0** | **不从 `confirmedEpisodeIds` 移除** → UI 仍可能「本集已确认」 |

## 4. 目标态主路径（生产级）

```text
编剧台确认成稿并送分镜
  → 分镜台高亮「拆镜」（可带 autoOpenBreakdown）
  → 拆本集或队列拆多集（可停 / 失败可重试）
  → 镜表：增/删/拆/合/排序 + 单镜线稿/上传
  → 构图：缺图优先批量线稿（可停）→ 故事板大图（按集）
  → 交接：硬/软门禁 checklist → 确认本集（状态诚实）
  → 打开导演台（无则创建并连边）→ 彩色关键帧批出
```

任一时刻：上游成稿 hash 变化 → **顶栏 Stale Banner**，禁止静默继续当「已同步」。

## 5. 默认产品决策（未另拍板则按此）

| 议题 | 默认 |
|---|---|
| 确认硬门槛 | 镜数≥1 **且** 构图覆盖≥60%（可在就绪条旁提供「仍要确认」二次确认） |
| 确认失效触发 | 增删拆合排序、改镜头字段保存、单镜/批量线稿成功写回、重拆/导入覆盖 |
| 故事板大图 | **按集存储**；切集显示该集 URL，无则空态 |
| 批量线稿默认范围 | 「当前集 · 缺图优先」；可选「当前集全部覆盖」 |
| 打开导演台 | 有则 focus；无则 spawn `director-desk` + edge + focus（对称编剧→分镜） |
| 删镜 | 必须项目确认框；确认后重排 index |
| 撤销 | 本地栈 20 步，仅本节点 `scriptBreakdown`（不含正在跑的网络任务） |
| 嵌入预览 | `embedded` 精简：只保留线稿网格/补缺图/同步；隐藏评分批审 |

## 9. 流程优化建议（产品层，不止补按钮）

1. **一条主按钮原则**：每一 Tab 只有一个主 CTA（拆镜：从成稿生成；镜表：无主 CTA 或「去构图补线稿」；构图：缺图批量线稿；交接：确认本集）。次要能力进 ⋯ 或次按钮。  
2. **按集心智**：顶栏集选择是「工作上下文」；故事板、确认、覆盖率数字必须全部跟随当前集。  
3. **贵操作可停可续**：凡 &gt;3 次模型调用，必须有进度 + 停止 + 部分成功保留（拆镜队列已做，线稿批量未做）。  
4. **状态诚实**：确认是交付契约，不是装饰；任何会影响下游导演台的变更必须摘确认并明示。  
5. **职责纯度**：分镜台视觉语言只谈「线稿 / 构图 / 故事板」；「评分 / 批审 / 关键帧」留给导演台。  
6. **与编剧台对称**：送分镜有 handoff；开导演应对称 spawn；破坏性弹窗统一 ConfirmHost；长任务可停。

## 10. 验收清单（生产级最低线）

- [ ] 成稿变更后顶栏 Banner 必现，且可一键重拆  
- [ ] 确认后改镜/出线稿 → 本集退出 `confirmedEpisodeIds`，UI 不再显示「已确认」  
- [ ] 切集后故事板大图不显示另一集的图  
- [ ] 可删镜；误操作可撤销至少一步结构变更  
- [ ] 批量线稿 / 宫格线稿可停止；已成功保留  
- [ ] 批量进行中刷新/关台有拦截  
- [ ] 确认在覆盖率不足时需二次确认或硬阻断（按拍板）
