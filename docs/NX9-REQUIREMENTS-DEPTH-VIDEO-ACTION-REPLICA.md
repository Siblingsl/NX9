# NX9 功能需求与解决方案：深度视频动作复刻 + 视频热门玩法

> **文档性质**：可执行的功能需求 + 落地方案。  
> **依据**：用户提供的「深度视频动作高度复刻」玩法说明 + 当前仓库代码行为 + 用户对 UI 落点的迭代决议。  
> **真相源优先级**：用户当次指令 → 本文 → `docs/skill-spec.md` / 内置 Skill 规范 → `约束开发要求.md` → 现有代码。  
> **编写日期**：2026-07-30 · 版本 **v0.4（生效 · 视频生成热门玩法入口）**  
> **落点决议（v0.4）**：热门玩法主入口改到 **`clip-gen`（视频生成）顶栏「热门玩法」**，交互对齐图像生成「专业工具」；**最小侵入**——未选玩法时视频节点行为不变；需要工具时**仅在输入框上方**出现槽位工具条。  
> **深度转换**：仍走后端可复用 API；UI 落在玩法工具条的深度槽内（不新建节点）。  
> **参考板**：恢复轻量 Mood Board（风格约束/堆图），**不再承载 Playbook 重 UI**。  
> **关联能力**：视频生成 `clip-gen`、参考板 `reference-board`（轻量）、既有图像深度通道 `depth-pass`、技能库 Skill、图像专业工具交互模式。

---

## 0. 一句话目标

把「**用深度视频锁定动作 / 用人物图锁定外貌 / 用场景图替换环境 → 一条提示词出片**」做成 NX9 内**可复用、可扩展的热门视频玩法**，并同时交付：

1. **独立完整 Skill 项目**（提示词契约 + 拼装包 + 样例，可在技能库查看修改）。  
2. **视频生成最小侵入**：顶栏「热门玩法」按钮（对齐图像「专业工具」）；选中后在输入框上方出现所需工具，不破坏普通文生视频路径。  
3. **深度视频转换**：在玩法工具条深度槽内完成（上传源视频 → 转深度）；后端抽可复用 API；**不新建**独立深度节点。  
4. **参考板保持轻量**：Mood Board 风格约束，不承担热门玩法配方 UI。

## 1. 问题陈述（为什么要深度视频）

### 1.1 用户痛点

| 做法 | 问题 |
|------|------|
| 直接把原视频交给视频模型作参考 | 原片含服装、颜色、背景、光影等噪声，模型易被干扰 → 肢体幅度变、手脚错位、节奏跑偏 |
| 只给人物图 / 场景图、无动作控制 | 能换人换景，但**动作不可控**，难做舞蹈 / 武术 / 整活复刻 |
| 玩法散落在口头提示词 | 新手不会写约束；热门玩法无法沉淀、无法一键复用、无法版本化 |
| 把玩法整板塞进参考板底部工作区 | 信息过载，破坏参考板轻量定位；与「视频才出片」的心智不一致 |

### 1.2 解法本质（产品语义，非供应商绑定）

| 输入角色 | 职责 | 视觉直觉 |
|----------|------|----------|
| **深度视频** | 只保留灰度空间层次、人物轮廓、肢体轨迹 → **锁定动作 / 走位 / 节奏** | 左半屏黑白深度 |
| **人物参考图** | **锁定角色外貌与服装** | 右半屏成片中的角色身份 |
| **场景参考图** | **替换环境**（霓虹街、室内等） | 右半屏成片背景 |
| **提示词** | 明确各参考的绑定关系 + 画幅 / 口型 / 禁则 | 用户文案 + Skill 模板 |

> **产品原则**：深度视频是**动作控制信号**，不是成片审美来源；人物图是身份锁；场景图是环境锁。三者在**视频热门玩法槽位**上分槽、可强制、可验收。

### 1.3 典型成片验收场景（黄金样例）

- 素材：双人舞蹈 / 武术短片（竖屏 9:16 优先）。  
- 转换：得到与原片时长、构图节奏一致的深度视频。  
- 参考：女主图、男主图、首尔霓虹街场景图。  
- 生成：成片中动作轨迹高度跟随深度视频；角色样貌跟人物图；背景跟场景图；无字幕水印；无角色互换 / 手脚畸形。  
- 可选：片头双语台词（中文引导句 + 外语发音）口型同步——作为**进阶约束**，非 MVP 阻断项。

## 3. 产品边界与非目标

### 3.1 本 epic 交付

1. Skill：`gen-depth-action-replica`（已具备模板结构）。  
2. **视频生成顶栏「热门玩法」** + 分类弹层（对齐图像专业工具）。  
3. 选中「深度视频动作复刻」后：输入框上方出现槽位工具（深度 / 人物 / 场景）；深度槽可转深度。  
4. 运行时装配提示词 + 参考图/视频送入视频连接；未选玩法时行为与改前一致。  
5. 参考板恢复/保持轻量 Mood Board。  
6. **本版不交付**独立 `depth-video` 画布节点。

### 3.2 非目标（本版不做 / 不强绑）

- 不把某一家视频模型的营销文案写进产品主 UI；连接层仍走「设置 → 连接」的视频连接。  
- 不在本版做完整「热门视频市场 / 社区下载中心」（可预留入口）。  
- 不替代导演台批出、分镜台、剪辑台主链路。  
- 不做实时摄像头深度；输入为已上传 / 已解析的短视频素材。  
- 不做保证 100% 帧级骨骼对齐的工程承诺；验收以「动作幅度、走位、节奏高度跟随 + 身份/环境锁生效」为准。  
- **不**把 Playbook 重 UI 塞回参考板底部工作区。

## 4. 术语

| 术语 | 定义 |
|------|------|
| **源动作视频** | 用户上传的舞蹈 / 武术 / 整活原片 |
| **深度视频** | 由源动作视频转换得到的灰度深度序列（或等价动作控制视频），用作动作锁 |
| **角色槽（Slot）** | 玩法工具条上带语义角色的媒体位：`depth_motion` / `character_*` / `scene` / `extra` |
| **玩法配方（Playbook）** | 一组槽位定义 + 默认提示词模板 + 校验规则 + Skill 绑定；可版本化 |
| **热门玩法** | 预置在视频生成顶栏菜单中的 Playbook（首发：`depth-action-replica`） |
| **装配提示词** | 根据槽位绑定与 Skill 模板生成的、可直接送给视频模型的最终提示词 |

## 5. 方案比选：主入口与深度转换放哪？

### 5.1 候选方案（含 UI 迭代）

| 方案 | 做法 | 结论 |
|------|------|------|
| **A. 塞进参考板内部** | 参考板承载 Playbook + 深度槽 | **已否决（UI 过重）** |
| **B. 扩写 `depth-pass`** | 单帧深度兼视频 | 不作主入口 |
| **C. 新建 `depth-video` 节点** | 独立节点 | **本版不做** |
| **H′. 视频生成 · 热门玩法（生效）** | 顶栏按钮对齐图像专业工具；工具仅出现在输入框上方 | **本版生效** |
| **J. 素材库转深度** | 板上只选用 | 后续可叠加 |

> **决议（2026-07-30 v0.4）**：主入口改为 **视频生成「热门玩法」**；最小侵入、不破坏普通视频生成；深度转换 UI 在玩法工具条深度槽内；后端 API 保持可复用。

### 5.2 本版架构（H′ · 生效）

```
[用户打开视频生成工作区]
        │
        ├─ 未选玩法 ──► 原有文生视频路径（不变）
        │
        └─ 顶栏「热门玩法」→ 深度视频动作复刻
                │
                ▼
        输入框上方槽位工具条
        （深度 / 人物1 / 人物2 / 场景）
                │
                ├─ 深度槽：上传源视频 → 转深度（POST /api/montage/depth-video）
                └─ 运行：Skill 装配提示词 + 参考图/视频 → 视频连接
```

### 5.3 UI 强制约束（最小侵入）

1. **顶栏**：仅增加「热门玩法」按钮（位置对齐图像「专业工具」，在模型选择左侧）。  
2. **未选玩法**：无芯片、无槽位条、无额外高度；工具栏 / 模式 / 参数 / 运行逻辑不变。  
3. **选中玩法**：在**输入框内部区域上方（topSlot）**出现：玩法芯片（可清除）+ 该玩法所需工具（槽位条）。  
4. **禁止**：为玩法整体改成弹窗工作室；禁止把槽位铺满整个底部工作区；禁止新建画布节点。  
5. **清除玩法**：一键回到普通视频生成。

### 5.4 后续若改选方案 C（非本版）

仅增加 `depth-video` 节点外壳，复用同一 `convertDepthVideo` API；热门玩法工具条可改为「选用上游深度 clip」。

## 6. 视频热门玩法 UI（对齐图像专业工具）

### 6.1 顶栏按钮

- 文案默认「热门玩法」；选中后显示当前玩法短名。  
- 弹层：分类列表（动作复刻 / 首尾帧 / …），条目含标题 + 一句 hint。  
- 首发条目：`深度视频动作复刻`；可挂 stub 玩法（如首尾帧）仅占位。

### 6.2 输入框上方工具（按需）

仅当玩法 `needsSlotTools=true` 时展示：

| 槽 | 操作 |
|----|------|
| 深度视频 | 上传源视频 / 转深度 / 直接填深度 / 清空 |
| 人物 ×N | 上传图片 / 清空 |
| 场景 | 上传图片 / 清空（可选） |

强约束未就绪时：禁用运行并提示原因；转换中阻断。

### 6.3 数据字段（写在 `clip-gen` 节点 data）

- `videoPlaybookId` / `videoPlaybookLabel`  
- `videoPlaybookSlots`  
- `videoPlaybookEnforce` / `videoPlaybookAspect`  

清除时置空上述字段。

### 6.4 参考板

保持 Mood Board：参考图 + 色板 + 风格备注。不承载 Playbook 下拉与深度转换主入口。

## 9. 端到端用户流程（P0）

1. 放置「视频生成」节点并展开工作区。  
2. 顶栏点「热门玩法」→ 选「深度视频动作复刻」。  
3. 输入框上方出现槽位：上传源视频 → 转深度；上传人物图（与可选场景图）。  
4. 在 prompt 区补句（风格/台词）。  
5. 点运行 → 装配提示词 + 参考媒体出片。  
6. 点芯片 × 清除玩法 → 恢复普通视频生成。

## 11. 验收标准（DoD）

1. 普通视频生成：不选玩法即可照常文生视频。  
2. 选中深度动作复刻：仅顶栏 + 输入框上方出现工具；可转深度、可出片。  
3. 清除玩法后无残留槽位条。  
4. 不出现新的画布节点 kind。  
5. 参考板无 Playbook 重 UI。  
6. Skill 修改 prompt-pack 后装配结果变化（或经缓存失效可见）。

---

## 12. 风险与开放问题

1. 深度转换质量依赖 FFmpeg 灰度方案，非真值深度传感器。  
2. 部分视频模型对「深度控制视频」支持度不一——连接层需可切换。  
3. 槽位条过宽时需横向滚动，避免撑高工作区。  
4. 日后若玩法极多，弹层需搜索/分组（对齐图像专业工具演进）。

## 14. 结论

- **主入口（生效）**：`clip-gen` 顶栏「热门玩法」，交互对齐图像「专业工具」。  
- **侵入边界**：未选玩法零干扰；选中后工具只在输入框上方。  
- **深度转换**：工具条深度槽 + 后端可复用 API；不新建节点。  
- **参考板**：轻量 Mood Board，不背热门玩法。  
- **Skill**：`gen-depth-action-replica` 继续作为装配真相源。
