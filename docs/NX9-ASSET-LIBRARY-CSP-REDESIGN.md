# NX9 服装 / 场景 / 道具库 · 设计重构规格

> **状态**：设计文档（先于实现）  
> **日期**：2026-08-11  
> **对照**：角色库已落地交互（卡片网格 → 更多·编辑 → 全页左右分栏），以及 `docs/NX9-ASSET-LIBRARY-GAP-SPEC.md` 中 Cos / Scn / Prop 功能项  
> **范围**：仅「上镜实体」三库——**服装 `costume`、场景 `scene`、道具 `prop`**。不扩写镜头/情绪/钩子/声音/风格。

---

## 0. 一句话目标

把服装、场景、道具从「左文字列表 + 右长滚动表单」升级为与角色库**同级的可扫视、可锁定、可协作**生产库；**壳层动线对齐角色库**，**内容模型与生成能力按各自生产语义定制**，禁止把角色设定板五分类照搬到物与环境上。

---

## 1. 设计原则

### 1.1 向角色库「借什么」

| 能力 | 角色库现状 | 三库是否继承 |
|------|------------|--------------|
| 浏览态卡片网格 | 正面站姿大图 + 角标 + 底栏名 + 「⋯」菜单 | **继承骨架**；封面图语义按 kind 换 |
| 进入编辑方式 | 不点卡片进编辑；「⋯ → 编辑」 | **强制继承** |
| 编辑态全页替换 | 隐藏列表区工具条噪音；顶栏：返回 / 名 / 复制@ / 锁定 | **强制继承** |
| 左右分栏独立滚动 | 左档案·Prompt·关系，右媒体主战场 | **继承布局哲学**；栏内区块按 kind 换 |
| 健康条可点过滤 | 重复 / 未使用 / 缺 Prompt / 未锁定 / 失效引用 | **继承机制**；指标定义按 kind 定制 |
| 跨库返回栈 | 角色↔服装、场景↔道具 | **继承**（UX-12/13） |
| 主生成分层 | 先「完整设定板」再下游衍生 | **仅服装/场景有「主设定板」概念**；道具用轻量「主参考板」 |

### 1.2 明确「不照搬」

| 角色库专属 | 为何不能搬到三库 |
|------------|------------------|
| 角色完整设定板 12×10 + 五类分类原图两步流水线 | 角色要锁「人」；服装锁「一套衣」、场景锁「一处空间」、道具锁「一件物」——复杂度与网格语义完全不同 |
| 表情 / 微表情 / 姿态 / 手部墙 | 服装可有破损/湿衣等**少量变体**，但不是表情矩阵；场景/道具更不需要 |
| 定妆脸锁、身份锁要点 | 场景用空间锚点；道具用标志细节；服装用廓形+面料+标志配饰 |
| 竖向 3:4 人物封面为唯一正确比例 | 场景宜宽景；道具宜方图或微竖；服装可竖（全身衣）但构图重心在衣而非脸 |
| 「未命名角色」文案与人设字段 | 各库空态、placeholder、健康文案必须 kind 化 |

### 1.3 实用性验收口诀

对每个库问四句，全部为「是」才算重构成功：

1. **一眼认出**：扫卡片能否判断「这套衣 / 这间房 / 这件物」？  
2. **两步锁定**：进编辑后，不滚屏能否完成「补主图或主设定板 → 锁」？  
3. **关系可跳**：被谁用、挂在哪，能点芯片去对方库并返回？  
4. **下游真用**：`@服装/@场景/@道具`、设定就绪、出图 enrich 读的是同一套 id + Prompt + 图？

## 2. 现状诊断（相对角色库）

### 2.1 壳层落差

| 维度 | 角色 | 服装 / 场景 / 道具（现状） |
|------|------|---------------------------|
| 浏览 | 卡片网格 | 左窄列表 + 小缩略图（仍偏「名单」） |
| 编辑进入 | 「⋯ → 编辑」全页 | 点列表即右侧详情（与角色动线分裂） |
| 详情骨架 | 左右分栏 | 单列 `max-w-2xl` 长滚动 |
| 主媒体 | 完整设定板 + 五类原图 | 服装有设定板生成；场景多参考；道具双槽位——**层级弱、视觉锚点不突出** |
| 关系 | 绑服装、发声音/情绪 | 服装有「被角色使用」；场景有 propIds；道具缺「被哪些场景挂接」回流 UI |

### 2.2 内容模型成熟度

| 库 | 字段壳 | 生成 | 协作 | 主要短板 |
|----|--------|------|------|----------|
| 服装 | 造型拆解较全 | `COSTUME_SHEET` 一键出板 | 角色 `costumeId` 单向偏强 | 设定板布局未硬锁；浏览非卡片；无「变体」产品位 |
| 场景 | 环境圣经字段齐 | 多参考 + sheet 模板文案 | propIds 已有；推荐列表弱消费 | 浏览非卡片；固定道具文本与实体并存易糊；无「主空间板」强展示 |
| 道具 | 轻量档案可用 | 无独立设定板 skill（仅 bible/image prompt） | `@道具`、预检已通 | 浏览非卡片；缺场景回流；缺轻量三视图板；landmarks 未视觉化 |

### 2.3 与 GAP 文档的关系

本规格**不重复** GAP 里已 ✅ 的预检/Mention/健康计算器本身；聚焦：

- **交互壳与信息架构**对齐角色库；  
- **各库主媒体与生成语义**产品化；  
- **关系区与实用性字段**补齐；  
- 给出可排期的 **P0 / P1 / P2**。

GAP 中仍相关的功能 ID：Cos-04/05/06、Scn-01～04、Prop-02/05/06/07、UX-04～06、UX-12/13。

## 3. 共享壳层重构（三库同一骨架）

### 3.1 信息架构

```text
素材库 · 上镜实体组
├─ Tab：角色 | 服装 | 场景 | 道具 | …
├─ 浏览态（服装/场景/道具与角色同级）
│    工具条：搜索 · 计数 · 健康筛选 · 新建 ·（服装可保留「批量设定板」）
│    主区：卡片网格（不进编辑）
│         卡片：主视觉 + 角标 + 名称 + 「⋯」
│         「⋯」：编辑 / 锁定·解锁 / 复制@ / 复制到私有·导入 / 删除
└─ 编辑态（全页替换主区）
     粘性顶栏：← 返回 · 名称(只读展示，改名在左栏) · 复制@ · 锁定 ·（可选更多）
     内容：左栏档案 | 右栏媒体（各自 overflow 滚动）
     进入编辑时：健康条 / 搜索新建条隐藏或折叠（与角色一致，减少噪音）
```

### 3.2 通用卡片契约 `EntityCardGrid`

抽取角色 `CharacterCardGrid` 为可复用模式（不必强行一个组件硬塞三种比例）：

| 契约项 | 说明 |
|--------|------|
| `resolveCover(item)` | 各库自己的封面优先级 |
| `aspect` | 服装建议 `3/4`；场景 `4/3` 或 `16/10`；道具 `1/1` |
| `objectPosition` | 服装 `top`；场景 `center`；道具 `center` |
| `badges` | 缺图 / 未锁 / 已锁 /（服装）未绑定角色 /（场景）无道具挂接警告可选 |
| `subtitle` | 可选一行次要信息：类别、场景码、材质… |
| `menu` | 编辑、锁、@、scope 动作、删除——与角色同构 |

**禁止**：点卡片空白进编辑（角色库已否决该方案）。

### 3.3 通用编辑契约 `EntityEditShell`

| 区域 | 放什么 | 不放什么 |
|------|--------|----------|
| 顶栏 | 返回、展示名、复制@、锁定 | 大段说明、生成进度全文（进度可在右栏媒体区） |
| 左栏 | 名、核心锚点字段、Prompt、Negative、关系芯片、高级折叠 | 大图墙 |
| 右栏 | **主设定板/主参考**（只读强调或可点放大）→ 次级媒体格 → 生成按钮组 | 与左栏重复的锁定 checkbox（锁只留顶栏一处） |

左右栏 **各自 `overflow-y-auto`**，导航/顶栏不随内容滚走（角色编辑已踩过的坑，三库一次性对齐）。

### 3.4 健康指标（按 kind 定制，禁止假零）

| 指标 | 服装 | 场景 | 道具 |
|------|------|------|------|
| 重复 | 同 scope 同 label | 同 | 同 |
| 未使用 | 无角色 `costumeId` 且无镜/@引用 | 无镜表 scene 绑定且无 @ | 无场景 `propIds` 且无 @ |
| 缺 Prompt | `promptEn` / costume prompt 空 | scene prompt 空 | prop prompt 空 |
| 未锁定 | `creative.locked !== true` | 同 | 同 |
| 缺主媒体 | 无 `sheetUrl` 且无参考图 | 无 `sheetUrl` 且无 `referenceUrls` | 无 `sheetUrl` 且无参考图 |
| 失效引用 | 角色绑定指向已删服装；镜表名对不上 | sceneCode/名对不上镜表 | `propIds` 指向已删；linked 场景失效 |
| 特色项 | **未绑定角色**（可选 chip） | **道具仅文本未实体化**（有 `props[]` 无 `propIds`） | **无标志细节**（landmarks 空） |

点击 chip → 过滤当前 Tab 卡片列表（UX-07）。

## 4. 服装库重构设计

### 4.1 产品定位

**服装 = 可复用的「穿在角色身上的造型套装」**，跨镜防换装漂移。  
它服务「谁在什么场合穿什么」，不是第二套角色身份系统。

### 4.2 卡片设计

- **封面优先级**：`frontFlatUrl`（设定板裁切）→ `sheetUrl` → `referenceUrls[0]` → 空态「无造型图」。  
  后续若设定板可裁「正面全身衣」格，优先用该裁切作封面（类似角色 `frontViewUrl`）。  
- **角标**：缺图 / 未锁 / 已锁；可选「未绑角色」。  
- **副标题**：`category` 或 `eraStyle`（如「战甲 · 现代」）。  
- **名称**：套装名（`@服装:名` 用此 label）。

### 4.3 编辑页信息架构

```text
左栏（档案与协作）
├─ 名称 / 类别 / 时代风格 / 标签
├─ 套装描述（防漂移主文案）
├─ 造型锚点：配色 · 面料 · 廓形
├─ 单品拆解：上衣/下装/外套/鞋履/配饰（可折叠「单品细节」）
├─ Prompt 区：注入 Prompt · Bible · Negative · 刷新
└─ 关系：被哪些角色使用（芯片跳转）· 适用角色/场景建议

右栏（媒体与生成）
├─ 【主】服装完整设定板（大图、可点放大、只读强调）
├─ 生成：主生成·服装设定板（单步即可，不搞五类）
├─ 补充参考图（1～N，默认 1～3）
└─ （P1）造型变体格：破损 / 湿衣 / 夜视低光 … 可选 0～4 槽
```

### 4.4 主媒体：服装完整设定板（单板硬锁，非五类）

**不要**复制角色「完整设定板 → 五类原图」。服装一张生产设定板足够。

建议固定版式（写入 prompt 硬锁，所有服装相同布局）：

```text
┌─────────────────────────────────────────────┐
│ 顶栏：服装完整设定板 · 名 · 类别 · 时代      │
├──────────┬──────────────────┬───────────────┤
│ 色彩/面料 │ 正面全身造型      │ 标志配饰特写  │
│ 色块+中文 │ （主视觉）        │ （1～2）      │
├──────────┼────────┬─────────┼───────────────┤
│ 材质注释 │ 3/4    │ 侧面    │ 背面          │
│ （简体） │ 全身   │ 全身    │ 全身          │
├──────────┴────────┴─────────┴───────────────┤
│ 细节条：领/袖口/开合/纹样/鞋履（4～6 格）   │
└─────────────────────────────────────────────┘
```

硬约束（对齐角色板经验，但内容不同）：

- 简体中文标注，禁乱码；  
- 全图同一套服装，禁漂移换装；  
- 人物可画人体衣架或弱化五官，**焦点在衣**；  
- 布局不可自由发挥。

实现落点：升级 `COSTUME_SHEET_PROMPT_TEMPLATE` / `buildCostumeSheetGenerationPrompt`，必要时抽 `packages/shared` 网格常量（类似 character-sheet-master，但规模小一个数量级）。  
UI：设定板置于右栏顶部大图；生成按钮在原「定妆」心智位改为「主生成·服装设定板」。

### 4.5 字段增删建议

| 动作 | 字段 | 理由 |
|------|------|------|
| 保留 | description, category, eraStyle, colorPalette, materials, silhouette, top/bottom/outerwear/footwear, accessories, tags, sheetUrl, referenceUrls, locked, prompts | 生产有用 |
| 强化展示 | recommendedCharacters → 与真实绑定合并展示 | 避免「建议名单」与「真实绑定」两套真相 |
| 新增（P1） | `variants?: CreativeVariantEntry[]` | 破损/湿衣等，轻量，默认空 |
| 新增（P1） | `frontFlatUrl?` | 设定板裁切出的封面用正面衣 |
| 弱化 | 详情内重复「锁定」checkbox | 顶栏唯一入口 |
| 不新增 | 表情墙、五类分类原图 | 越权成角色库 |

### 4.6 协作与实用性

| 场景 | 行为 |
|------|------|
| 角色绑服装 | 左栏关系区列出角色芯片 → 跳角色编辑并返回 |
| 分镜 @服装 | 已通；卡片菜单「复制@」降低摩擦 |
| 镜级换装 Cos-06 | **P2 可选**：不阻塞壳层重构；若做，在分镜侧 overrides，库内只展示「被哪些镜覆盖」只读 |
| 批量设定板 | 保留工具条入口，但编辑页内仍有单件主生成 |

### 4.7 服装动线（目标）

```text
浏览卡片认出套装
  → ⋯ 编辑
  → 左填造型锚点 / 右点「主生成·服装设定板」
  → 确认板面合格 → 锁定
  → 回角色库绑定 或 分镜 @服装:名
```

## 5. 场景库重构设计

### 5.1 产品定位

**场景 = 可复用的「空间与光环境圣经」**，防场景漂移、供分镜 sceneCode / @场景 / 环境同步。  
道具挂在场景上，灯光/天气/时代留在场景字段——**不拆灯光库、不把道具文本当实体。**

### 5.2 卡片设计

- **比例**：宽景 `4/3` 或 `16/10`（第一眼是「地方」不是「人」）。  
- **封面优先级**：`coverUrl`（主景裁切）→ `sheetUrl` → `referenceUrls[0]` → 空态「无场景图」。  
- **角标**：缺图 / 未锁；可选「道具未实体化」。  
- **副标题**：`sceneCode` 或 `timeOfDay · lighting`（如 `S01 · 夜 · 霓虹`）。

### 5.3 编辑页信息架构

```text
左栏
├─ 名称 / 场景码 / 世界观·时代 / 标签
├─ 空间锚点描述（结构、材质、固定标识）
├─ 时间天气 · 光照 · 色彩
├─ 固定道具：
│    · 主：propIds 芯片多选 +「去建档」
│    · 次：旧 props[] 文本只读迁移提示（或折叠「兼容旧数据」）
├─ Prompt · Negative · 刷新
└─ 创作推荐（折叠默认收起；分镜台可点选写入本镜）

右栏
├─ 【主】场景空间设定板（大图可放大）
├─ 生成：主生成·场景设定板（单步）
├─ 多参考图网格（上限沿用 MAX_ENV_REFERENCE_IMAGES）
│    每张可删、可点放大；首图作 img2img 约定写清
└─ 不出现角色式表情/五类墙
```

### 5.4 主媒体：场景空间设定板

单板硬锁建议版式：

```text
┌──────────────────────────────────────────────┐
│ 顶栏：场景空间设定板 · 名 · 场景码 · 时段     │
├────────────────────────────┬─────────────────┤
│ 主确立镜头（宽景英雄图）   │ 色彩/光照注释   │
│                            │ （简体）        │
├──────────────┬─────────────┼─────────────────┤
│ 另一机位/纵深 │ 关键结构     │ 固定道具位示意 │
├──────────────┴─────────────┴─────────────────┤
│ 锚点条：门/窗/招牌/地面材质/天光方向（文字+小图）│
└──────────────────────────────────────────────┘
```

硬约束：简体中文、禁乱码、同一空间不瞬移改装修、固定道具位与 `propIds` 描述一致。  
落点：强化 `SCENE_SHEET_PROMPT_TEMPLATE` + 编辑页右栏主图位（现状 sheet 埋在参考区，需抬升为「主」）。

### 5.5 字段增删建议

| 动作 | 字段 | 理由 |
|------|------|------|
| 保留 | description, sceneCode, worldView, timeOfDay, weather, lighting, colorTone, tags, referenceUrls, sheetUrl, locked, prompts, propIds | 核心 |
| 主路径 | `propIds` | 实体协作 |
| 兼容 | `props: string[]` | 折叠展示；提供「一键从文本建议建档」P1 |
| 降级 UI | recommended* 六组 | 默认折叠，避免假完整感 |
| 不新增 | 独立灯光库、场景五分类原图 | 违背 Scn-04 |

### 5.6 协作与实用性

| 场景 | 行为 |
|------|------|
| 挂道具 | 芯片开关 propIds；点芯片打开道具编辑（返回栈） |
| 环境圣经同步 | 保持现有双向；编辑页诚实提示「保存后同步」 |
| 分镜 | sceneCode / 名绑定；健康「失效引用」可修 |
| 导演/出图 | 读 sheet 或首参考 + scene prompt |

### 5.7 场景动线（目标）

```text
宽景卡片认出空间
  → ⋯ 编辑
  → 左写空间锚点与光照 / 右生成空间设定板 + 补多参考
  → 勾选固定道具 propIds
  → 锁定 → 分镜绑场景或 @场景:名
```

## 6. 道具库重构设计

### 6.1 产品定位

**道具 = 跨镜连续性锚点的「物件身份卡」**。  
轻于服装与场景：默认不需要五面墙设定板；**标志细节 landmarks 比漂亮渲染更重要。**

### 6.2 卡片设计

- **比例**：`1/1` 产品英雄图。  
- **封面优先级**：`coverUrl`（正面格裁切）→ `sheetUrl` → `referenceUrls[0]` → 空态「无参考图」。  
- **角标**：缺图 / 未锁 / **缺标志细节**。  
- **副标题**：`category · materials`（如「手持 · 黄铜」）。

### 6.3 编辑页信息架构

```text
左栏
├─ 名称 / 类别 / 材质 / 标签
├─ 外观与用途
├─ 标志细节 landmarks（必填提示：健康「缺标志细节」）
├─ 关联场景：优先 sceneIds 芯片（P0/P1），linkedScenes 文本兼容
├─ Prompt · Negative · 刷新
└─ 关系：被哪些场景挂接（由全库反查 propIds，芯片跳转）

右栏
├─ 【主】道具主参考图（大）
├─ 生成（P1）：主生成·道具三视图板（可选，轻量）
├─ 补充参考 1～3
└─ （可选）细节特写槽：铭文/刮痕/机关 — 最多 3，手动上传优先
```

### 6.4 主媒体：轻量「道具三视图板」（可选，非角色级）

若做生成，**一张小板**即可：

```text
┌─────────────────────────────────────┐
│ 道具设定板 · 名 · 类别              │
├──────────┬──────────┬───────────────┤
│ 正面英雄 │ 侧面/背面│ 标志细节特写 │
└──────────┴──────────┴───────────────┘
```

硬约束：简体标签、同一物件、landmarks 必须画进特写格。  
**P0 可不做生成**，先把上传主参考 + landmarks + 关系 UI 做实用；生成放 P1。

### 6.5 字段增删建议

| 动作 | 字段 | 理由 |
|------|------|------|
| 保留 | description, category, materials, landmarks, tags, sheetUrl, referenceUrls, locked, prompts | 够用 |
| 升级 | `linkedSceneIds?: string[]` | 与场景 propIds 双向；文本 `linkedScenes` 兼容 |
| 新增（P1） | `detailUrls?: string[]` 或 variant 槽 | 刮痕特写 |
| 明确不做 | 完整分类五原图、表情矩阵 | 过重 |

### 6.6 协作与实用性

| 场景 | 行为 |
|------|------|
| 场景 → 道具 | 已有 propIds；道具页必须能反查「挂在哪些场景」 |
| 预检缺口 | chip → tab=prop 建议建档（已有方向，编辑壳对齐后体验闭环） |
| 分镜本镜道具 Prop-06 | P2；库侧预留只读「被引用次数」即可 |
| 连续性修复 | landmarks + 锁图 供 consistency-repair 对照 |

### 6.7 道具动线（目标）

```text
方卡认出物件
  → ⋯ 编辑
  → 左写 landmarks（必填心智）/ 右传主参考
  → （可选）生成三视图板
  → 锁定 → 回场景勾选挂接 或 @道具:名
```

## 11. UI 验收清单

1. 服装/场景/道具浏览均为卡片；**点击卡片不进编辑**；仅「⋯→编辑」。  
2. 编辑顶栏不随内容滚动；左右栏独立滚。  
3. 三库封面比例符合 §7（竖衣 / 宽景 / 方物）。  
4. 各库有且仅有一套「主媒体」心智：服装设定板 / 场景空间板 / 道具主参考（或三视图板）。  
5. 不出现角色五类分类原图、表情墙搬进三库。  
6. 服装↔角色、场景↔道具可芯片跳转并返回。  
7. 锁定后卡片角标立即为「已锁」。  
8. 健康数字可点过滤；无假零。  
9. `@服装/@场景/@道具` 从卡片菜单一键复制。  
10. 空态文案 kind 化，并给出「新建 / 从预检补档」下一步。
