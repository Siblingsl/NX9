## 8. 验收口诀

1. 从设定就绪点缺口进库，补完能回预检并落到原缺口行。  
2. 点卡片就能编；批量时不靠单卡 `⋯`。  
3. 锁定与主生成在顶栏；详情不再同权大按钮。  
4. 阻塞=总闸、健康=细则；修完有清过滤引导。  
5. 只读/预览一眼可辨。  
6. 不宣传绑当前镜；用复制 @。  
7. 不做清单零回潮。
