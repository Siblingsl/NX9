# NX9 素材库 · 原型与操作动线审计

> **日期**：2026-08-12  
> **性质**：只出文档，不改代码  
> **范围**：`AssetLibraryModal` 壳层 + 各子库卡片/详情 + 设定就绪往返 + 制作台深链 + 健康/阻塞反馈  
> **依据**：现行 `apps/web/src/panels/AssetLibraryModal.tsx`、`asset-library/*`、`AssetReadinessPanel`、制作台 AssetsHub  
> **前提**：功能闭环（OPEN-LOOPS）已基本收口；本文只谈「原型是否合理、动线是否说得清」  

---

## 0. 怎么读

| 符号 | 含义 |
|------|------|
| **P0** | 易迷路 / 易误操作 / 语境丢失，优先修壳 |
| **P1** | 能用但费解，明显加步骤或加认知负担 |
| **P2** | 打磨项，不挡出片 |
| **已有能力** | 代码已有，但摆放/文案/可见性让人用不上 |

**原则（验收约束）**

1. 动线变更必须能指出「少点几次 / 少猜一步 / 少丢语境」。  
2. 禁止为好看打断：开库 → 选条 → 补媒体/Prompt → 锁定 → 回分镜/预检。  
3. 不做新紫色仪表盘；沿用现有 `surface / line / brand / ink`。  

---

## 1. 一句话结论

功能账本已齐，**体验债转到「壳层信息架构」**：进入编辑方式不统一、全页编辑时顶栏语境条消失、主生成动作埋在长详情里、健康/阻塞/筛选三层反馈并存但优先级不明、模态盖住画布导致「拖进分镜」说得出做不到。

下一阶段应是 **UX 短动线改造**，不是再加字段。

## 2. 现行壳层地图（便于对照）

```
┌─ Header：标题 | 私有/公共 | 阻塞摘要 | 回收站 | 关闭
├─ Tab 分组条（上镜实体 / 词典 / 声音）        ← 全页编辑时收起
├─ 健康条（按 Tab 指标 chip + 影响分析）       ← 全页编辑时收起
├─ 语境条（来自设定就绪 / 返回栈 / 建议建档） ← 浏览+编辑共用 ✅
├─ 搜索 / 新建 / 筛选 / 批量
└─ 内容：卡片网格  ⇄  全页详情（粘性顶栏：回列表 · 上一实体 · @ · 锁 · 主生成 · …）
```

> 壳层现状以改后代码为准；**残留半落地**见 `NX9-ASSET-LIBRARY-UX-RESIDUAL.md`。
**已做对的部分（勿再当缺口）**

- 私有 / 公共 scope 切换入口明确  
- Tab 分组（实体 vs 词典 vs 声音）  
- 健康 chip 可点过滤；阻塞摘要可跳 Tab  
- 详情分区锚点（角/服/场/道）  
- 跨库返回栈（`navStack`）  
- 设定就绪 `returnHint` / 建议建档条（列表态）  
- 粘性详情顶栏（返回 / 复制@ / 锁定 / 删除）  
- 卡片状态徽标（缺图 / 未锁 / 覆盖中）

## 3. 不合理不合理（原型 / IA）

| ID | 问题 | 现状证据 | 用户感知 | 建议方向 | 优先级 |
|----|------|----------|----------|----------|--------|
| UX-P01 | **进编辑路径隐晦** | 卡片主体不可点；靠 `⋯ → 编辑` | 「点卡片没反应」 | 点封面/标题进详情；`⋯` 留给次要操作 | **P0** |
| UX-P02 | **全页编辑吞掉语境条** | `shellFullEdit` 时 Tab/健康/**returnHint** 整段不渲染 | 从设定就绪深链进详情后，找不到「返回预检」 | 语境条与「返回来源」在详情顶栏常驻 | **P0** |
| UX-P03 | **主生成不在粘性条** | 顶栏有锁/@/删；设定板/五分类生成在详情深处 + GenSettings | 「生成」与「保存字段」抢注意力，主动作难找 | 粘性条增加「主生成」菜单；设置折叠在旁 | **P0** |
| UX-P04 | **Chrome 条带过多** | Header→Tab→健康→语境→搜索，列表首屏被挤 | 先看见控件再看见资产 | 合并健康+阻塞为一条；搜索并入 Header 右侧 | **P1** |
| UX-P05 | **回收站整页替换** | `showTrash` 替换 Modal 主体 | 编辑中点垃圾桶丢光上下文 | 抽屉/侧栏；或确认「离开编辑」 | **P1** |
| UX-P06 | **切 scope 选中易丢** | `handleScopeChange` 几乎不保留选中 | 私有↔公共来回对账费劲 | 同 id/同源尽量保留；否则保留 query | **P1** |
| UX-P07 | **词典 Tab 仅公共** | 私有下镜头/风格不可见并自动跳走 | 「我的镜头库呢？」认知落差 | 私有顶栏注明「词典在公共」；跳转时 toast 解释 | **P1** |
| UX-P08 | **情绪/钩子幽灵残留** | 自动踢回其他 Tab，但 KIND_META 仍有降级文案 | 偶发看到空态/兼容话术 | 导航彻底隐藏；仅深链旧 id 时只读提示 | **P2** |
| UX-P09 | **「阻塞」与「健康」双入口** | Header `AssetBlockingSummary` + 下方 `AssetHealthBar` | 两套数字，不知先点谁 | 阻塞=跨 Tab 总闸；健康=当前 Tab 细则；文案写死关系 | **P1** |
| UX-P10 | **新建版本 vs 锁定** | 两者都改 lock/snapshot 语义相邻 | 怕「锁了又新建」搞不清 | 顶栏「版本」说明：新建=+rev 并锁快照；锁=禁止漂移 | **P1** |
| UX-P11 | **详情仍偏长表单** | 分区锚点有，但分区仍多字段堆叠 | 扫视成本高 | 默认折叠「进阶」；缺图/缺 Prompt 自动锚到对应区 | **P1** |
| UX-P12 | **左右栏职责不清（角色）** | 左档案右媒体，生成控件散落两侧 | 不知道先填左还是先出右 | 固定顺序：身份 → 媒体门槛 → Prompt → 关系 → 生成 | **P1** |
| UX-P13 | **公共模板预览 vs 可编辑** | 服装等需「立即导入」条 | 改了半天发现是只读预览 | 只读态全局水印/顶栏「预览·导入后可编」 | **P1** |
| UX-P14 | **批量与单卡菜单重叠** | BatchBar + 每卡 `⋯` | 多选后仍以为要点菜单 | 进入批量模式后弱化单卡菜单，强调批量条 | **P2** |
| UX-P15 | **拖拽进分镜被模态挡住** | 库卡可 drag，但 Modal `z-260` 盖住画布 | 文档说能拖，实操拖不到镜格 | 列表态提供「复制@」为主；或支持「钉到当前选中镜」按钮 | **P0**（承诺与能力对齐） |

## 4. 操作动线不清（按任务）

### L1 设定就绪 → 补齐 → 回预检

| 步 | 现状 | 断点 |
|----|------|------|
| 预检点缺口开库 | 有 `navigateRequest` + `returnHint` | ✅ |
| 落到对应 Tab/条目 | 通常可用 | ⚠ 若直接进全页编辑，**语境条消失（UX-P02）** |
| 补图/锁/生成 | 能做 | ⚠ 主生成难找（UX-P03） |
| 回预检 | 列表态有「返回设定就绪」 | **P0**：详情态无同级入口 |

**目标短动线**：预检 → 库详情（顶栏始终「返回设定就绪」）→ 补齐主门槛 → 一键回预检刷新。

---

### L2 选条目 → 补媒体 / Prompt → 锁定

| 步 | 现状 | 断点 |
|----|------|------|
| 找到条目 | 搜索+健康过滤可用 | ⚠ 进编辑靠 `⋯`（UX-P01） |
| 看见缺什么 | 卡片徽标 + 健康 chip | ⚠ 两套信号未合并说明（UX-P09） |
| 补媒体 | MediaSlot 在详情 | ⚠ 长滚动；未默认锚到「最缺」区（UX-P11） |
| 锁定 | 顶栏有锁 | ✅ |
| 复制引用 | 顶栏「复制@」 | ✅ |

**目标短动线**：点卡进详情 → 顶栏锁/@/主生成 → 缺什么滚到哪 → 锁 → 复制@回分镜。

---

### L3 健康问题 → 过滤 → 修复 → 复核

| 步 | 现状 | 断点 |
|----|------|------|
| 发现问题 | 阻塞摘要 + 健康 chip | ⚠ 双入口（UX-P09） |
| 过滤列表 | chip 可点 | ✅ |
| 修复 | 影响分析内重绑 | ⚠ 抽屉信息密；服/道/镜/风/声入口在影响分析里，列表态用户不一定点开 |
| 复核 | 需手动清过滤 | ⚠ 缺「已修复·清除过滤」引导 |

**目标短动线**：阻塞 → 跳 Tab 并过滤 → 打开第一条 → 重绑/补图 → 自动提示清除过滤。

---

### L4 公共预览 → 导入私有 → 深化

| 步 | 现状 | 断点 |
|----|------|------|
| 浏览公共 | OK | — |
| 识别只读 | 部分 Tab 有导入条 | ⚠ 不统一（UX-P13） |
| 导入后继续编 | toast + 进编辑 | ⚠ 切回私有后选中/过滤可能丢（UX-P06） |

---

### L5 库内关系跳转（角色↔服装↔场景↔道具）

| 步 | 现状 | 断点 |
|----|------|------|
| 关系芯片跳转 | 有 `jumpToAsset` + `navStack` | ✅ |
| 返回上一实体 | 「← 返回某某」 | ⚠ 仅列表态语境条；详情顶栏只有「返回」到**列表**，不是返回上一实体 |

**建议**：详情顶栏区分「回列表」与「回上一实体（栈）」。

---

### L6 Desk / 制作台深链 → 库 → 回去

| 步 | 现状 | 断点 |
|----|------|------|
| 制作台「在素材库打开」 | 有 returnHint | ✅ |
| 分镜拖库卡 | 协议有 | ❌ 模态挡住（UX-P15） |
| 关闭后回 Desk | 靠用户自己 | ⚠ returnHint 关闭=关库，不保证聚焦原 Desk 字段 |

| ID | 文案/概念 | 问题 | 建议 |
|----|-----------|------|------|
| UX-C01 | 「全库畅通」 | 只表示无**阻塞**键，不含未使用/未锁 | 改为「无阻塞项」或副文案说明 |

## 6. 目标原型方向（薄改，非大重构）

### 6.1 三态壳层

| 态 | 显示 | 隐藏 |
|----|------|------|
| **浏览** | Header + Tab +（合并后的）健康条 + 搜索 + 网格 | — |
| **编辑** | Header 精简 + **详情顶栏（含来源返回）** + 详情 | Tab/健康可收为「库」图标抽屉，默认不占竖向 |
| **回收站** | 侧抽屉 | 不卸掉编辑态除非确认 |

### 6.2 详情顶栏信息架构（统一各子库）

```
[← 回列表] [← 回上一实体?]   标题   |  复制@  锁定  主生成▾  更多（发布/版本/删除）
来源语境（设定就绪 / 制作台）—— 编辑态也显示
```

### 6.3 卡片交互

- 单击封面/标题 → 编辑  
- `⋯` → 复制@ / 锁 / 发布 / 删除 / 导入  
- 多选模式：左上角勾选；隐藏易误触的单卡破坏性操作  

### 6.4 「拖进分镜」诚实化

短期二选一（文档阶段先定产品）：

**A.** 弱化拖拽宣传，强化「复制@ / 绑定到当前镜」按钮；或  
**B.** 浏览态支持「选择目标镜后一键绑定」，不依赖跨模态 HTML5 drop。

## 8. UX 验收口诀

1. **从设定就绪点缺口进库，补完后不靠记忆也能回预检**（编辑态也行）。  
2. **点卡片就能编，不必先找三点菜单**。  
3. **锁定与主生成在首屏顶栏可见**，不必滚过分区。  
4. **阻塞数字与健康 chip 说人话**，用户知道先点哪。  
5. **不宣传做不到的拖拽**；能做的绑定路径不超过两步。  
6. **不做清单零回潮**（情绪库/团队库等）。
