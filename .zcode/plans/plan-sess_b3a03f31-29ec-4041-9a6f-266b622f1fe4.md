# 节点卡片双主题重设计：暖纸工坊 × 炭黑摄影棚（CSS 双皮肤）

## 背景与现状

- 全部 19 种画布节点卡片汇聚在一套 DOM：`BlockShell.tsx`（主画布外壳，`CanvasNodeShell` 是其封装）、`CardShell.tsx`（舞台模式，含折叠卡）、`NodeSummaryBody.tsx`（统一卡面）、`NodeSockets.tsx`（连接点）、`registry.tsx`（加载占位卡）。
- 样式集中在 `apps/web/src/styles/node-stage-card.css`，颜色走 `desk-palette.css` 的 `--desk-*` 变量。
- 主题切换：workspace store `canvasAppearance.theme` → body `nx9-app-dark(-body)` + 画布根 `nx9-theme-dark/light`；**当前两主题卡片形态完全相同，仅换色**。
- 本次目标：一套 DOM 不变，浅色/深色各一套**形态完全不同**的卡片设计与 UI，随主题自动切换。

## 改动内容

### 1. `apps/web/src/styles/node-stage-card.css` — 重写为三段式（核心）

**共通布局段（保留不动）**：卡片 280px 尺寸、ports 绝对定位、`.react-flow__node { overflow: visible }`、socket 禁 transform 等 RF 约束（含注释）、`data-socket-style`（dot/plus/hidden）行为逻辑。

**浅色设计段（`:root` 默认 + `.nx9-theme-light` 作用域）· 暖纸工坊**：
- 卡面：暖纸微渐变（沿用 `--desk-card-bg`）、10px 圆角、1px 棕灰描边、柔和双层暖投影
- accent：`__accent` 由左侧竖条改为**顶部整条节点色带**（height 3px、width 100%）
- 头部：纸白底 + 底部细下划线；标题深棕
- 媒体区：**白衬相框**（外层 3px 纸白衬边 + 内 1px 细描边、6px 圆角）
- 统计：**纸片格子**（浅底细边小方格）
- 徽章/标签：纸片胶囊 + 细实线边
- 按钮：纸面按钮，主按钮古铜金实底
- socket：暖白芯圆点 + 棕描边
- 状态：选中 = 古铜金描边 + 暖影加深；运行 = 暖蓝脉冲

**深色设计段（`.nx9-theme-dark` / `.nx9-app-dark` / `.nx9-app-dark-body` 作用域）· 炭黑摄影棚**：
- 卡面：炭黑渐变、14px 圆角、rgba 白 10% 细亮边、顶部 1px 内高光线（inset shadow）、深投影
- accent：**左侧发光竖条**（3px + accent 色 glow）
- 头部：透明底、无下划线，改为底部金色渐变 hairline（`::after`）
- 媒体区：**暗底内嵌框**（#0f1012 底 + 内描边、8px 圆角）
- 统计：**行内式**（grid 改 flex 行内 + 分隔符，无格子底）
- 徽章：暗色玻璃胶囊
- 主按钮：暗底金边、悬停发光
- socket：暗芯 + 彩色描边光晕
- 状态：选中 = 金线 + 外光晕；运行 = 青蓝脉冲光

折叠卡（stage-deck collapsed）与 registry 加载占位卡共用同类名，自动继承两套皮肤。

### 2. `apps/web/src/styles/desk-palette.css` — 扩充少量结构 token

按主题新增：`--desk-card-radius`（浅 10px / 深 14px）、`--desk-card-radius-media`（浅 6px / 深 8px）等圆角/阴影类 token；**现有颜色变量语义不动**（大量 desk CSS 在消费）。

### 3. 小组件微调（不改 DOM、不改类名）

- `BlockShell.tsx` / `CardShell.tsx`：`Loader2` 硬编码的 `text-teal-300` → 新增 `.nx9-stage-card__spin` 类，颜色走 `--desk-run`，两主题各自呈现。

## 不改动

- 19 种节点业务组件与卡面内容逻辑；连线、小地图、画布背景（范围外）
- F-043 摘要卡规范（标题 + 关键状态 + 最多 1 主操作）保持
- 已确认无测试引用卡片类名，无测试回归风险
