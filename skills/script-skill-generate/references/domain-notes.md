# 平台与片种语感

| 平台/片种 | 选题与节奏要点 |
|-----------|----------------|
| 抖音/快手短剧 | 开场快钩；每集 800–1800 字；强反转；口语对白 |
| 漫剧/条漫感 | 表情与动作夸张；少写实运镜词（本 skill 本就禁镜头词） |
| 长剧/连续剧 | 人物弧更长；集末钩子服务追剧 |
| 小红书/种草叙事 | 生活场景锚点；人设清晰；少血腥暴力 |

## 与 agent-screenplay 对齐

- 场景头：`## Sxx | 内景/外景 · 地点 | 时间`
- 对白：`角色名：台词` / `角色名（状态）：台词`
- 禁止：`【场景】`、引号对白、镜头词、非终章 `（完）`

导演控制中的「图片风格 / 视频风格」只影响下游分镜语感，本 Skill 仍只写叙事层。
