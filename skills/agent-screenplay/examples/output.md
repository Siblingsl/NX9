# 期望输出（契约通过）

```text
第1集 人生规划表

## S01 | 内景 · 咖啡厅 | 白天

李稳坐在靠窗卡座，衬衫洗得发白，桌上放着柠檬水和一张「人生规划表」。手机响，他立刻接起。

李稳：红姨，我到了！你说的那个姑娘……靠谱吗？
红姨（电话）：怎么不靠谱？人家自己开公司，有房有车。稳儿，规划表带了没？
李稳：带着呢。从结婚到孩子上小学，都列好了。

门被推开。两个黑西装先扫场，随即让开。一个女人走进来：黑长外套，墨镜，红唇。她在李稳对面坐下，摘下墨镜。

李稳：请问……您是不是坐错了？
苏曼：李稳？红姨介绍的？
李稳：是是是！可红姨说您是开公司的……
苏曼（淡）：嗯，公司。做进出口。不听话的，就沉江。

门外突然撞进几个男人，为首刀疤脸拎着棒球棍砸上桌沿。柠檬水溅了李稳一裤子，他吓得缩到桌腿后。

刀疤：苏曼！码头那批货，今天给交代！
苏曼不紧不慢端起茶壶，热茶泼向刀疤脸，随即用碎壶嘴抵住他脖子。

苏曼：这店是我的。回去告诉你们老板，拿脑子谈，别拿棍子。

刀疤一伙灰溜溜退走。苏曼低头看还缩在桌下的李稳，把一张名片拍到他面前。

苏曼：假男友。明天下午三点，我派人接你。不来，就让刀疤去你小区找「英雄」。

她戴上墨镜离开。李稳瘫在椅上，盯着裤脚茶渍，手机却亮起一条未读：明天的课表，已发送。
```
