# 禁止形态（契约失败）

## 失败 1：JSON 包裹
```json
{"episodes":[{"index":1,"title":"第1集","bodyMd":"..."}]}
```

## 失败 2：错误场景头 + 引号对白
```text
第2集 试用期

【场景：出租屋外，下午】

司机："李稳？"
李稳："我就是。"
```

## 失败 3：镜头词 / 完结误标
```text
第1集 测试

咖啡厅。白天。

特写：李稳的手在抖。镜头推进到人生规划表。

李稳说道：「我到了。」

（完）
```

## 失败 4：续写复述多集 / 体例漂移
同一次输出里第1集用 `## S01 | …`，第2集改用 `【场景】`；或指令只要第2集却把第1集全文再写一遍。
