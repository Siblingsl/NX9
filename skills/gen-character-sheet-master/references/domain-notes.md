# 模型适配
设定板用于角色 ID 锁定；完整设定板与五类分类原图**版式脱钩**，但身份必须一致。

## 两步语义
1. **角色完整设定板**：Character ID Bible。独立版式总览；不承担生产级槽位裁切；所有角色布局必须相同；**不迁就五类布局**。
2. **五张完整分类原图**：以完整设定板为唯一角色参考展开；分类局部网格裁切回填槽位。

## 完整设定板网格（12×10）
- 画布：1536×1152 像素、4:3 横版
- row0：顶栏（角色完整设定板 + 名 + 身份 + 年龄 + 性格×3）
- row1-3 / col0-2：色彩参考（7 色块 + 简体标签）
- row4-6 / col0-2：身份锁要点（8 条简体中文，不画人）
- row1-3 / col3-8：全身三视图（正/侧/背）
- row4-6 / col3-8：脸部六角（正/侧左/侧右/斜左/斜右/后脑勺）
- row1-6 / col9-11：表情矩阵 3×3（通常/微笑/认真；惊讶/害羞/思考；困扰/悲伤/平静）
- row7-9 / col0-11：细节特征 12（左眼/右眼/眉毛/鼻子/嘴唇/耳朵/下颌/皮肤/刘海/侧发/后发/手部）

## 完整设定板硬原则
- 锁脸、锁色、锁五官结构、锁全身轮廓
- 简体中文标签；禁止英文标签、乱码、伪文字
- 禁止图片漂移：全图同一人物
- 不要求与五类原图格子一一对应

## 五类分类母图（生产裁切）
- identity：3×2（仅剪影 + 主身份四视图；禁止情绪特写）
- expressions：4×2（筛选八表情）
- micro-expressions：3×2（六微表情）
- head-and-posture：上排 5 头 + 下排 3 姿
- costume-and-hands：上排 4 细节 + 下排 5 手部

文字规则：图片内所有文字使用简体中文；负面词包括英文标题、英文标签、乱码、伪文字、watermark、logo、extra limbs、identity change、blurry face、identity drift。
