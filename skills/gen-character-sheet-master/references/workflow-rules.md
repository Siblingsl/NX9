# 工作规则
对齐 `buildCharacterMasterSheetPrompt`（完整设定板）与 `buildCharacterSheetCategoryPrompt`（五类）。

## 两步流程（强制）
1. **主生成·设定板**：只生成 1 张「角色完整设定板」→ `fullSheetUrl`。版式 12×10 对所有角色完全相同；**与五类版式脱钩**。
2. **生成五类原图**：仅当完整设定板已确认后执行；`referenceImageUrl` 必须为 `fullSheetUrl`；再按分类局部网格裁切回填。

## 完整设定板硬规则
- 画布 1536×1152、4:3；标题为「角色完整设定板」。
- 固定分区：顶栏 / 色彩参考 / 身份锁要点 / 全身三视图 / 脸部六角 / 表情矩阵 3×3 / 细节特征 12。
- 所有可见文字必须是简体中文；禁止英文标签、乱码、伪文字。
- 禁止图片漂移：全图同一角色脸/发型/体型/服装。
- 禁止自由排版、增删合并格子、把五类版式硬套进本图。

## 五类分类母图
- 每张保持 4:3，至少 2K、优先 4K；画布基准 1536×1152。
- 每张分类母图顶部约 8% 为分类标题条，其余区域按该分类 cols×rows 等分后填充和裁切。
- **主身份 / 剪影**：3×2；仅剪影 + 四视图全身；禁止情绪特写与表情墙。
- **表情系统（8）**：4×2；仅平静/微笑/愤怒/紧张/惊讶/害怕/悲伤/坚定。
- **微表情（6）**：3×2；眼部紧张/微笑/嘴部用力/微恐惧/呼吸控制/咬唇。
- **头部结构 / 姿态**：上排 5 头肩 + 下排 3 更宽全身。
- **服装细节 / 手部动作**：上排 4 细节 + 下排 5 手部。
- 每个子格底部使用准确的简体中文短标签；禁止英文、乱码、伪文字和水印。
- 输出前检查完整设定板、五类图片、裁切坐标、比例、清晰度和同一角色身份。
