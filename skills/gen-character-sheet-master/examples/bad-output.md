# 负例
- 只生成单张美图，无多格 ID 锁。
- 「角色完整设定板」版式与锁定网格不一致（增删格、乱排、合并、跨格）。
- 「角色完整设定板」出现乱码、英文标签、伪文字。
- 「角色完整设定板」出现图片漂移（各格不是同一人物/五官比例漂移）。
- 「角色完整设定板」硬套五类分类原图版式，或缺少色彩参考/身份锁要点/脸部六角/表情 3×3/细节 12。
- 未先确认完整设定板就直接生成五类，或以非完整设定板图片作为五类角色参考。
- 「主身份 / 剪影」出现情绪特写通栏，或下半幅出现表情墙（平静/微笑/愤怒…）。
- 主身份全身挤在过窄竖条里，头脚贴边，偏宽体型被横向压扁，裁切后面部模糊。
- 「表情系统（8）」超过 8 格，或混入好奇/放松等未筛选表情，或夹带全身/剪影。
- 「微表情（6）」仍用 5×1 细长竖条，裁切后半脸切片；或标签错成「用表情」；或缺咬唇 / 多出第 7 格。
- 「头部结构 / 姿态」仍用 8×1 把头像与全身挤在等宽细竖条；或下排姿态过窄被横向压扁；或放松≈紧张几乎无差别；或裁切落到标题条只剩「头部/结构/姿态」文字碎片。
- 「服装细节 / 手部动作」仍用 9×1 混排细竖条；或触脸变成半身大肖像；或裁切落到标题条只剩「角色/分类设定图」文字碎片。
