# 角色设定板 Master

## 这个 skill 用来做什么
CHARACTER ID LOCK：先用一张**独立版式**的「角色完整设定板」锁定身份（不迁就五类布局），再展开五张完整分类原图供裁切回填。所有格子同一身份。

## 输入要求
角色描述、性别年龄体型、服装锁定、appearanceLock、forbidden、style。

## 输出要求（两步）

### 第一步：角色完整设定板（1 张）
- 固定 1536×1152、4:3；12×10 锁定网格；**所有角色版式必须完全相同**
- **与五类分类原图版式完全脱钩**；本图只做 ID 圣经，不承担生产裁切
- 模块：
  1. 顶栏：角色完整设定板 + 名 + 身份 + 年龄 + 性格×3（简体中文）
  2. 色彩参考：7 色块 + 简体标签（发色/瞳色/肤色/眉色/服装色/阴影色/基调色）
  3. 身份锁要点：8 条简体中文（脸型/眼周/鼻形/嘴唇/刘海/体型/服装/同一角色优先）
  4. 全身三视图：正面 / 侧面 / 背面
  5. 脸部六角：正面 / 侧左 / 侧右 / 斜左 / 斜右 / 后脑勺
  6. 表情矩阵 3×3：通常/微笑/认真；惊讶/害羞/思考；困扰/悲伤/平静
  7. 细节特征 12：左眼/右眼/眉毛/鼻子/嘴唇/耳朵/下颌/皮肤/刘海/侧发/后发/手部
- **硬约束**：简体中文标签、禁止乱码/英文标签、禁止图片漂移、全图人物一致性

### 第二步：五张完整分类原图
以完整设定板为**唯一角色参考**依次生成；版式按各类局部网格，与完整设定板不同。每个子格必须使用准确的简体中文短标签；输出至少 2K、优先 4K。

### 分类职责

1. **主身份 / 剪影**（3×2）— 正侧剪影 + 主身份四视图；禁止情绪特写与表情墙
2. **表情系统（8）**（4×2）— 平静/微笑/愤怒/紧张/惊讶/害怕/悲伤/坚定
3. **微表情（6）**（3×2）
4. **头部结构 / 姿态**（上 5 + 下 3）
5. **服装细节 / 手部动作**（上 4 + 下 5）

## 工作流程
填字段 → **主生成·设定板** → 人工确认完整设定板 → **生成五类原图** → 按分类局部坐标裁切 → 回填对应子项 → 检查清晰度和身份一致性。

## 约束与边界
禁止重新诠释角色；禁止新脸新发型；禁止自由排版、移动、合并、跨格；禁止英文标题/标签、乱码和伪文字；禁止图片漂移；最大一致性。
完整设定板与五类原图版式可以不同，但五类必须复制完整设定板中的同一角色。
