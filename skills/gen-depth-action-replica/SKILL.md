# 深度视频动作复刻

## 这个 skill 用来做什么
把「深度视频 = 动作锁 / 人物图 = 身份锁 / 场景图 = 环境锁」装配成一条可送视频模型的提示词。
普通参考视频含服装、颜色、背景噪声，易干扰动作；深度视频只保留灰度空间层次与肢体轨迹，帮助模型专注动作、走位与节奏。
本 Skill **不**执行视频转换；转换在参考板深度槽内完成。本 Skill 只负责提示词契约与拼装包。

## 输入要求
- 玩法：`depth-action-replica`（参考板 Playbook）
- 必填槽：`depth_motion`（深度视频 URL）、至少 1 张 `character` 人物图
- 建议槽：`scene` 场景图
- 可选：用户补句（风格、台词、画幅、禁则）
- 拼装包：`templates/prompt-pack.md`（quality / template / constraints / overlay）

## 输出要求
装配提示词必须显式包含：
1. 风格或场景一句话
2. 每个角色：`外貌和服装严格参考@人物N`
3. 动作总锁：`全部动作、走位、身体姿态、互动、节奏严格参考@深度视频，完整复刻，不得自行修改`
4. 多角色时出场顺序跟随深度视频
5. 技术约束：画幅、一镜到底（若勾选）、无字幕/文字/水印、无错位/互换/畸形
6. 用户补句插入约定位置，不得冲掉锁句

## 工作流程
1. 参考板选择玩法「深度视频动作复刻」
2. 深度槽：上传源动作视频 → 转深度 → 原/深对照确认（或直接填入已有深度视频）
3. 填入人物图、场景图；按需锁定
4. 填写补句（风格 / 台词等）
5. 一键「生成提示词」：读取本 Skill `prompt-pack` + 槽位变量装配
6. 用户预览可编辑 → 确认写入 `assembledPrompt` 并 emit 引用包
7. 下游 `clip-gen` 消费装配提示词 + 人物图 + 深度视频出片

## 约束与边界
- Skill 不内置 API Key；出片走当前视频模态活跃连接
- 不保证 100% 帧级骨骼对齐；验收以动作幅度/走位/节奏高度跟随 + 身份/环境锁为准
- 禁止把深度视频当成成片审美来源
- 禁止角色互换、手脚畸形、擅自改编动作、字幕水印
- 台词口型为进阶约束，不阻断无台词出片
